# --scan External Vulnerability Scanning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `--scan <trivy|grype|custom>` flag (requires `--report`) that runs an external scanner against the image's merged filesystem and embeds the scanner's raw output in the JSON report.

**Architecture:** A new pure-ish module `src/scan.rs` holds command resolution (pure function), command execution (spawns `sh -c`, parses stdout as JSON with a raw-string fallback), and a thin wrapper that materializes the merged filesystem via the existing `extract::export_ocirender` path into a tempdir before delegating to command execution. `src/main.rs` adds `--scan`/`--scan-cmd` flags with cross-flag validation and wires the result into the existing `--report` branch. `src/report.rs` gains one new optional field on `ReportImage`.

**Tech Stack:** Rust 2021, `clap` (`ValueEnum` derive for the scanner enum), `serde`/`serde_json` (already dependencies), `tempfile` (already a regular dependency), `std::process::Command` for spawning.

## Global Constraints

- Spec source of truth: `docs/superpowers/specs/2026-07-01-scan-flag-design.md`.
- `--scan` requires `--report` — enforced by clap itself (`requires = "report"`), not manual code.
- `--scan=custom` requires `--scan-cmd`; `--scan-cmd` is rejected when `--scan` is `trivy` or `grype` — enforced by a manual `validate_scan_args` function (clap's declarative attributes can't express this value-conditional pair).
- Built-in preset templates, exact strings: `trivy` → `"trivy rootfs --format json {path}"`; `grype` → `"grype dir:{path} -o json"`. `{path}` is replaced with the tempdir's path via simple string substitution (`str::replace`), supporting multiple occurrences.
- Commands run via `sh -c "<resolved command>"` — Unix-only, no Windows branch (imgchk has no existing Windows support to preserve).
- `ScanResult` fields and semantics: `tool` (the `--scan` value as a string), `command` (fully resolved, post-substitution), `exit_code` (`Option<i32>`, `None` only if the command couldn't be spawned at all), `output` (parsed JSON `Value` if stdout parses, else a JSON string of raw stdout, `null` if not spawned), `error` (`null` on a normal run regardless of the scanner's own exit code — except exit code 127, "command not found", which is treated as an imgchk-level error with `output: null`).
- A scan failure never blocks or alters the rest of the report — `layers`/`suspicious_files` always print.
- No exit-code gating on scan findings, no timeout on the external command, no scanner installation/bundling, no TUI integration, no normalization of scanner output into imgchk's own schema.
- Extraction for scanning always uses a fresh, ephemeral tempdir — independent of `-o`/`cli.output`, cleaned up after the scan regardless of outcome.
- Documentation is part of this plan, not a follow-up: `README.md` (Features bullet, Report Mode section's JSON example + prose, a jq recipe), `CLAUDE.md`'s Core Behavior list, and `EXAMPLES_HELP` in `src/main.rs` must all be updated (per project convention — see `feedback_docs_with_cli_changes` memory).

```rust
use std::process::Command;

/// Resolve `tool`'s command against `path`, run it via `sh -c`, and capture
/// the result. Exit code 127 ("command not found" — the standard POSIX
/// shell convention) is treated as an imgchk-level error since it means the
/// scanner never actually ran; any other exit code (including non-zero
/// codes scanners use to signal "vulnerabilities found") is a normal run.
pub fn run_resolved_command(tool: ScanTool, custom_cmd: Option<&str>, path: &Path) -> ScanResult {
    let tool_name = tool.name().to_string();
    let command = resolve_command(tool, custom_cmd, path);

    match Command::new("sh").arg("-c").arg(&command).output() {
        Ok(out) => {
            let exit_code = out.status.code();
            if exit_code == Some(127) {
                let stderr = String::from_utf8_lossy(&out.stderr).trim().to_string();
                return ScanResult {
                    tool: tool_name,
                    command,
                    exit_code,
                    output: None,
                    error: Some(if stderr.is_empty() {
                        "command not found".to_string()
                    } else {
                        stderr
                    }),
                };
            }
            let stdout = String::from_utf8_lossy(&out.stdout).to_string();
            let output = serde_json::from_str::<serde_json::Value>(&stdout)
                .unwrap_or(serde_json::Value::String(stdout));
            ScanResult {
                tool: tool_name,
                command,
                exit_code,
                output: Some(output),
                error: None,
            }
        }
        Err(e) => ScanResult {
            tool: tool_name,
            command,
            exit_code: None,
            output: None,
            error: Some(format!("failed to spawn command: {e}")),
        },
    }
}
```

```rust
use std::path::PathBuf;

use ocirender::ImageSpec;
use tempfile::tempdir;

use crate::extract;
use crate::image::LayerInfo;

/// Extract the image's merged (whiteout-resolved) filesystem to a fresh,
/// ephemeral tempdir — independent of `-o`/`cli.output`, always cleaned up
/// after the scan regardless of outcome — then run `tool`'s scan command
/// against it.
pub fn run_scan(tool: ScanTool, custom_cmd: Option<&str>, layers: &[LayerInfo]) -> ScanResult {
    let tool_name = tool.name().to_string();

    let dir = match tempdir() {
        Ok(d) => d,
        Err(e) => {
            return ScanResult {
                tool: tool_name,
                command: String::new(),
                exit_code: None,
                output: None,
                error: Some(format!("failed to create tempdir: {e}")),
            };
        }
    };

    let dir_path: PathBuf = dir.path().to_path_buf();
    if let Err(e) = extract::export_ocirender(layers, ImageSpec::Dir { path: dir_path }) {
        return ScanResult {
            tool: tool_name,
            command: String::new(),
            exit_code: None,
            output: None,
            error: Some(format!("failed to extract image for scanning: {e}")),
        };
    }

    run_resolved_command(tool, custom_cmd, dir.path())
    // `dir` (TempDir) drops at the end of this scope, removing the tempdir.
}
```

```rust
fn validate_scan_args(cli: &Cli) -> anyhow::Result<()> {
```
